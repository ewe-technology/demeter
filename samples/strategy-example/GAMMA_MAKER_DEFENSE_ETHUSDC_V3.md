## 3. 乖離規則怎麼實作

**旗標與目標比例**（`daily_ema_frame`、`divergence_flags`）：每個 UTC 日收盤算 d = 收盤 ÷ EMA100 − 1。旗標從 OFF 開始（EMA 種子日 2017-08-17），OFF 時 d ≥ `DIVERGENCE_ON`（0.40）變 ON，ON 時 d < `DIVERGENCE_OFF`（0.20）才變 OFF，中間維持原狀（遲滯）。旗標 ON 時 F′ = 0，OFF 時 F′ = F。虛擬帳戶與 F 完全不受影響，ON 期間照常運作，所以解除當天可以直接取當下的 F。

`daily_ema_frame` 的輸出多三欄（`signal_daily_*.csv` 也有）：`d`、`diverged`（0／1）、`Fp`。`DIVERGENCE_RULE = False` 則 `diverged` 全 0、`Fp` = `F`，等於 v2。

**真實帳戶**：
- `target_fraction_for` 改回傳 `Fp`。`follow_work`（每日追隨）與 `pre_placement_swap`（重建的規模）都從這裡讀，所以不用另外改：旗標變 ON 的隔天 00:00，`follow_work` 看到目標 0 但還有部位，就以 0 重建，等於全撤成 USDC。
- `diverged_for` 讀當天旗標。`rescale_work` 的上破重建分支多一個判斷：旗標 ON 時直接以 0 重建（撤出），不先重建再撤，省一次 swap 成本。這是實作選擇，規格書沒寫同一天的順序。
- ON 期間帳面全是 USDC，`rescale_work` 因為沒有部位直接返回，`compound_work` 因為 LP 比例是 0 也只把新手續費留在 USDC。

**解除（OFF）當天**：F′ 回到 F，再照原本規則 3 追隨：|F′ − 目前 LP 比例| ≥ 12.5% 才重建，規模是 F′ × 資產，其餘留 USDC。12.5% 是比例差距的門檻，不是 F′ 的下限：
- F′ = 0：不重建（規格書事件表 2021/5/19、2024/3/19 屬這種，結束時 F = 0，「轉為一般撤出」）。
- 0 < F′ < 0.125：差距不夠，繼續留 USDC。
- F′ ≥ 0.125：以 F′ × 資產重建；F′ ≥ 0.999 為滿額。
- 解除後不分階段回補；回補只存在於虛擬帳戶。

## 7. 已知限制與待辦

- **整段跑不了**：池分鐘資料只到 2026-01-04。補 2026/1/5～8/31 的 ETH/USDC 0.05% 池分鐘資料後，把 `date_ranges` 的整段那行解除註解即可。2021/5/6 起跑時旗標已 ON（2021/4/2 起），開局全 USDC。
- **規格書的整段數字對不上的前提**：整段結果要用 0.1% 平價、補上 claim 規則與成功報酬的處理才可比（規格書的數字是扣費前，不扣成功報酬與執行手續費，這點和程式一致）。
- **24 種判定時間平均**：規格書 v3 改用平均驗證，程式只跑 UTC 0 時，沒有做時間偏移與價格誤差的驗證。
- **同一天順序**：旗標 ON 與上破重建同一天發生時，v3 直接撤出；規格書沒寫順序，要向作者確認。
- **F 的定義**：沿用 v2 的 `F_BY_VALUE = True`（虛擬 LP 價值比例）；規格書第 10 節仍列為待決，若改成階段值要重算。
- **未模擬**：規格書第 5 節的用戶入金（ON 期間新入金以 USDC 持有）、多用戶 claim 合併；回測只有單一帳戶。
